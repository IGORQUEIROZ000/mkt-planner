# Instalar no Windows e no iPad

Este guia é para a versão publicada em uma URL HTTPS. **Não é preciso Node.js no computador do usuário.** Nenhuma publicação foi realizada automaticamente nesta entrega. Se ainda não existe endereço, siga o [guia de publicação](GUIA-PUBLICACAO-SEM-NODE.md) quando decidir publicar.

## Windows — Chrome ou Edge

1. Abra a URL definitiva e aguarde carregar completamente.
2. Use **Instalar aplicativo** no Planner ou a opção de instalação do menu do navegador. O nome/posição do comando varia por versão.
3. Confirme a instalação e abra pelo ícone criado.
4. Importe um exemplo, salve uma alteração e feche. Abra novamente e confira os dados.
5. Desligue a rede, reabra pelo ícone e confira o indicador Offline. Abra calendário, Estúdio e um material local. Gere um backup.

Se não houver opção de instalação, confira se está na URL HTTPS e se o navegador oferece PWA. É possível usar pelo navegador. Não abra `index.html` como arquivo e não considere o localhost do computador como endereço do iPad.

## iPad — Safari

1. Abra a mesma URL HTTPS definitiva no Safari e aguarde o carregamento completo.
2. Toque em **Compartilhar → Adicionar à Tela de Início** e confirme.
3. Abra pelo novo ícone, importe seu planejamento e salve um conteúdo.
4. Feche e reabra para conferir persistência. Desligue a rede e repita a consulta/edição.
5. Exporte um backup usando o seletor de arquivos do sistema e confira onde o JSON foi salvo. Teste sua restauração em outro navegador antes de depender apenas daquela instalação.

## Outros celulares

No Android compatível, use a instalação pelo menu do Chrome/Edge. No iPhone/Safari, o caminho é semelhante ao iPad. As opções do sistema e as políticas de armazenamento variam. Esses dispositivos precisam de verificação real; testes de largura no computador não os homologam.

## Dados e atualizações

Cada navegador/perfil/origem tem seu banco. Mesmo no mesmo aparelho, Safari/Chrome e modos diferentes podem ter dados separados. Transferência é manual por backup; nada é sincronizado na nuvem.

Quando aparecer nova versão, salve o editor/revisão e conclua as edições de outras abas. Use Salvar conteúdo e atualizar ou Atualizar agora. Sem rede, continue na versão instalada e atualize depois. Não remova o aplicativo ou apague dados sem backup.

Registre o resultado da instalação real: modelo do aparelho, sistema, navegador/versão, data e testes executados. Esta entrega não declara homologação física sem essa verificação.
